## 这个模型是什么

由「低位上影线模型2(双栏) v2.3」拆出的**高位栏**——`registry.json` 里登记为
「高位上影线模型（风险观察名单）」。与低位栏正好相反：

| | 低位栏 `low_shadow2` | 高位栏 `high_shadow`（本模型） |
|---|---|---|
| 方向 | 偏多 · 买入候选 | **偏空 · 风险观察名单** |
| 位置判定 | `c <= 0.6 × hh60` | **`c >= 0.90 × hh60`**（v2.1） |
| 命中口径 | 后续上涨 | **后续下跌** |
| 形态/评分 | 同一套阈值 | 完全沿用，未改 |
| 量能 | `v/MA5 ≤ 2.2` 且 `v/前日 ≥ 0.5` | **v1.3 起两个量比同时落在 `[0.85, 1.4]`** |

## 数据入口（符合原接入契约）

1. **样本池**：读 `UNIVERSE_JSON`（`common/state/universe.json`，4606 只，已 ST + 立信剔除），
   不再自行抓全市场列表；
2. **K 线**：优先读共同前置层 `common/state/klines/<code>.csv`；
   本地/独立流程无共享缓存时，回退到自带的新浪财经日K接口（`scale=240`，70 根），
   并缓存到 `state/klines_cache.json.gz`，便于离线复跑与回溯；
3. **一致性校验**：目标日 K线收盘价与样本池 `price` 偏差 >2% 的股票跳过
   （复权口径或数据源不一致时避免误判）；
4. **推送**：`push_wechat()` 读 `PUSHPLUS_TOKEN` 走 PushPlus markdown 通道，随每日
   统一流水线自动推送；`--no-push` 仅供本地调试跳过，推送失败不影响落盘。

## 口径与待核对项（重要）

- `config.json` 的 `shape` / `score` 与 `low_shadow2/config.json` **逐项一致**：
  上影≥2倍实体、上影/全幅≥50%、下影/全幅≤25%、上影/收盘≥1.5%、阴线、非跌停；
  评分权重 40/30/30。
- **量能已改（v1.3）**：不再是 `v/MA5 ≤ 2.2` 且 `v/前日 ≥ 0.5`，
  改为 `volume.volume_band = [0.85, 1.4]`，`apply_to = [vol_ratio_prev, vol_ratio]`
  （两个量比必须同时落在闭区间内）。旧的 `ma5_cap` / `prev_min` 仅保留兼容，
  `detect()` 已不使用；关闭 `volume_band.enabled` 即回退到旧口径。
- 低位栏 `detect()` 里本就内置了 `else: c >= min_ratio * hh60` 的高位分支，
  本栏就是把它启用（同一份 `model_core`，两份 config 的双栏结构）。
- **`position.min_ratio = 0.8` 是双栏对称推定值**（低位 0.6 → 高位 0.8 的中间带
  0.6~0.8 为中性区），**不是云盘原值**。请用云盘 `config.json` 核对后改这一项即可，
  其余参数无需改动。
- 数据源差异：低位栏生产用东财前复权日K，本栏独立运行用新浪日K；近期 60 日
  无除权的股票差异可忽略，有除权的股票已由上面的价格一致性校验剔除。
- 本栏是**风险观察名单，不产生买入信号**，请勿与低位栏的买入候选混用。

## v2.0 变更：写入第二条件 F（2026-11-15）

**用户口径**：量比 `0.85~1.4`（第一条件保持不变），**按候选 F 写入第二条件**。

### 两个条件

| | 条件 | 配置位置 | 生效方式 |
|---|---|---|---|
| 第一条件 | `vol_ratio_prev` 与 `vol_ratio` 同时落在 `[0.85, 1.4]` | `volume.volume_band` | `detect()` 的 `sig` |
| 第二条件 | **F**：`20 <= posq_prev < 60` 且 `pre2_pattern != "阴阳"` | `filter` | 独立 `pass_filter()` |

- `posq_prev` = T-1 收盘在 60 日高低区间的分位%（`hh60/ll60` 取 `[i-60, i)` 区间，
  含 T-1、不含信号日 T，与 `detect()` 的 `rolling(60).shift(1)` 同口径）；
- `pattern` = T-2/T-1 阴阳组合（阳 = 收盘 > 开盘），「阴阳」= 先阴后阳；
- 实现与 `low_shadow2/config.filter` **同构**：`detect()` 只输出特征列、
  `sig` 判定口径零改动，`pass_filter()` 在核心命中后做二次过滤；
  **`filter.enabled=false` 即一键回滚到 v1.3 纯量比口径**。

|---|---|---|---|---|
| C0 仅第一条件 | 5,690 | +0.092% / 50.12% | -0.053% / 46.54% | -0.194% / 45.05% |
| **F（本次写入）** | **1,886** | **+0.358% / 53.87%** | **+0.329% / 48.89%** | **+0.424% / 48.51%** |

> 属**名单质量过滤**，不是统计显著的 alpha。详见 `state/pre2day_conditions.json`。

## v2.1 变更：位置阈值 0.8→0.90（2026-11-16）

**用户质疑**：金牌家居 11-16 收 14.05，而 10-23 收 15.85（60 日盘中高 16.71），
已跌 15.9% 却被判「高位」。

**根因**：`min_ratio=0.8` 是从低位栏对称翻转的推定值；对窄幅震荡股，60 日最低价
可能已达最高的 80% 以上（本例 13.63/16.71=81.6%），比率口径恒真——跌到区间底部
仍判高位。分位口径给出 13.6%（区间底部），两者结论相反。

**改动**：仅 `config.json` 的 `position.min_ratio` `0.8 → 0.90`，version→v2.1，
`_change_log` 追加一条；`high_shadow_screener.py` 只更新头部注释。

**依据**（330 根长历史、296 交易日，量比 0.85~1.4 + 形态）：

| 口径 | 信号数 | T+1 均值/胜率 | T+5 均值/胜率 | 聚类t5 |
|---|---|---|---|---|
| 比率≥0.80 + F | 1,875 | +0.361%/53.97% | +0.429%/48.43% | 1.20 |
| **比率≥0.90 + F** | **307** | **+0.344%/59.61%** | **+0.456%/50.16%** | -0.16 |
| 分位≥0.50 + F | 463 | +0.142%/52.48% | +0.306%/46.44% | 0.50 |
| 比率≥0.95 + F | 6 | -0.450%/33.3% | -0.857%/33.3% | — |

分位口径最差（定义「高位」应看比率而非区间分位）；0.90 是甜点，0.95 过窄。
改后 11-16 名单由 2 只收敛到 1 只（世纪瑞尔 90.2% 保留，金牌家居 84.1% 剔除）。
详见 `高位上影线_位置口径缺陷核实.md` 与 `高位上影线_位置口径修正_回溯对比.csv`。
