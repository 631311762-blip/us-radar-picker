# 怡达模型 📈

源自怡达股份（300721）2026年8~11月走势提炼的选股模型，已上线 GitHub 并接入统一前置流水线，每个交易日自动运行 + 微信推送。

**GitHub 仓库**：https://github.com/631311762-blip/us-radar-picker （目录 `yida/`）

## 模型逻辑

| 步骤 | 规则 |
|---|---|
| ① 阴跌前置 | 放量首日(D1)前收盘较过去60日最高价跌幅 ≥ 30%，且股价 < MA60 |
| ② 平台放量 | 连续4天成交量均为前20日均量的 2~7 倍 |
| ★ 涨停豁免 | **D1若为涨停板（主板10cm/双创20cm/北交30cm），封板导致量能不足2倍属正常，豁免D1倍数**，其余D2~D4仍严格2~7倍 |
| ③ 量能平稳 | 四天量能变异系数 CV < 20%（排除逐日爆量，怡达原型仅6.8%）|
| ④ 提示日 | 放量**第2天(D2)**收盘价买入 |
| ⑤ 退出机制 | 关注5天，任一触发即停止：收盘价跌破D1实体中点(开+收)/2，或成交量<放量四天均量的一半；触发当日按最高价结算 |
| ⑥ 命中判定 | 关注期内最高收益 ≥ 3% |

参数见 `yida/config.json`，可随时调整。

## 回溯表现（2026年全A股）

| 口径 | 信号数 | 命中率 | 平均收益 |
|---|---|---|---|
| 旧版·死拿5日 | 410 | 88.0% | 10.9% |
| **新版·带退出（当前）** | 410 | **92.2%** | 10.6% |

新版退出机制表现分解：

| 退出原因 | 数量 | 命中率 | 平均收益 |
|---|---|---|---|
| 持有到期 | 178 | 96.6% | 13.8% |
| 缩量退出 | 93 | 93.5% | 9.7% |
| 破位退出 | 139 | 85.6% | 7.2% |

> 退出机制把"5日内跌回去"的票锁定在触发前浮盈上，命中率提升4.2个百分点。

**涨停豁免（v3）**：原规则下 D1 涨停封板导致量能不足2倍会被漏掉（如易点天下7-31涨停20%但量仅1.86倍）。豁免后 2026 新增17个信号，**命中率100%、平均收益17.2%**，合并后整体命中率 92.7%→93.0%。新信号包括：易点天下+23.5%、肯特股份+61.1%、中国科传+39.7% 等。

原型案例验证：
- 怡达股份 D1=11-17、提示日=11-18（收16.74），阴跌-39.6%、放量5.32倍、CV 6.8%，5日收益 +24.7% 命中 ✅
- 易点天下 D1=7-31（双创涨停20%、量1.86倍触发豁免）、提示日=8-3（收32.34），5日收益 +23.5% 命中 ✅

## 接入方式（已上线）

怡达模型**不是独立 workflow**，而是并入仓库现有的统一流水线：

- **样本源**：读取 `common/state/universe.json`（前置流水线样本池，已剔除 ST/立信/监管立案/次新）
- **K线**：复用 `common/state/klines` 共享缓存（严格离线）
- **调度**：已在 `common/registry.json` 注册，由 `common/run_all.py` 每日统一调度
- **台账**：`ctx.record()` 落盘，自动进入次日统一回溯与参数修正
- **推送**：复用 `common/notify.py` 的 PushPlus 通道（`PUSHPLUS_TOKEN` secret 已配置）

### 微信推送格式（三段式·精简）

```
怡达 11-23 · 提示4 退出0
━━━━━━━━━━━━━━━━
【一、提示日的票 11-19·4只】
`688757` 胜科纳米 买28.76 观察2日 +6.7%
`301396` 宏景科技 买113.71 观察2日 +7.8%
...
【二、观察中·未破位 3只（5日内）】
`300721` 怡达股份 买16.74 观察3日 +24.7%✓
`688820` 盛合晶微 买99.4 观察3日 +6.5%✓
...
【三、⚠️ 退出告知 N只（停止关注）】   ← 仅当日有新破位时出现
`603220` 中贝通信 破位退出 买15.46 结算+5.6%
```

看到提示日后**只观察5天**，分流规则：

- **第一段**：最新提示日（放量第2天D2）当天的票
- **第二段**：历史入选、**未破位**、**仍在5日观察期内**的票 → 每天跟踪当前收益
- **第三段·退出告知**：5日内触发破位（收盘<D1实体中点）或缩量（量<四日均量一半）
  - 退出日=当日 → 推一条"已退出"告知，**之后永久拉黑不再推**
  - 退出日早于当日 → 视为已告知过，静默不再推（破位日是K线客观事实，无需额外状态文件）
- **观察满5日**未破位 → 观察期结束，不再推送
- 提示日天然滞后：形态需4天放量走完确认，故提示日通常比当前交易日早2~4天

统一流水线 `a-share-pipeline.yml` 每天 **北京时间 15:10** 自动运行，怡达模型随之执行并推送。

## 使用

```bash
# 仓库内运行（正式：选股+台账+推送）
python3 yida/daily_yida.py

# 本地复跑不推送
python3 yida/daily_yida.py --no-push
```

推送 token 由 GitHub Secrets 的 `PUSHPLUS_TOKEN` 提供，本地运行需设置同名环境变量。
