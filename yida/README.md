# 怡达模型 📈

源自怡达股份（300721）2026年8~11月走势提炼的选股模型，已上线 GitHub 并接入统一前置流水线，每个交易日自动运行 + 微信推送。

**GitHub 仓库**：https://github.com/631311762-blip/us-radar-picker （目录 `yida/`）

> **当前版本：v6.0 形态精选分级版**（2026-11-25）。一套引擎通吃两种强势形态：**🔵平台型**（怡达原型）+ **⚡加速型**（南极光原型）。基于 4 组平台样本 + 1 组加速样本标定。在 v5.4 D2 实时预判基础上，新增**四重形态精选**（D1质量/D2回吐/平台企稳/假破位分级）+ **持有期统一3日**，信号从410精简到83、质量大幅提升——见下。

> **v6 核心升级（2026-11-25，四轮回测验证）**：
> 1. **持有期**：据 1/3/5 日回测，3日是收益/风险最佳平衡点（3日+2.03%/准40% vs 5日+1.36%/准36.6%且深亏翻倍），**平台型与加速型统一跟3日**（原平台5日名存实亡：288只中153只撑不到第5日）。
> 2. **D1质量**：D1须**阳包阴**（阳线实体包住前日阴线）；**D0涨停则豁免**——救回"涨停后整理"的追涨型样本（超声、肯特二次）。
> 3. **D2回吐**：D2收盘不得回吐 D1 涨幅一半；D0涨停按涨停幅半幅计算。深亏票 39 只拦掉 35 只（90%）。
> 4. **平台企稳**：D1前5日收盘 CV≤3%（黄金样本1.5~2.5%）；无平台的"空中楼阁"直接剔除。
> 5. **★假破位分级**：平台后曾破位、D1火速收复者标★一级优先推送（26只，5日+7.69%/准65.4%）；仅分级不硬过滤（避免误伤无破位的肯特/南极光）。
> 6. **v5.1反抽过滤停用**（`risk_filter:false`）：其规则B误伤超声黄金样本，v6新规已更精准覆盖防诱多目的。
>
> **v6 整体效果**：信号 410→83（精选20%），5日收益 +1.36%→**+4.21%**，准确率 36.6%→**48.8%**，深亏率 9.7%→**3.7%**；★一级信号 5日 **+7.69%、准确率65.4%**。**黄金样本5/5全保留**（`python3 golden/verify.py` 校验通过）。**已否决规则**：D2高开大阴线过滤（数据不支持——深亏票0/39命中该形态，高开大阴票本身5日+6.18%/零深亏，且误伤超声/肯特）。
>
> 详见报告：`怡达模型_平台企稳假破位_形态研究.html`、`怡达模型_D0涨停豁免_D2回吐规则验证.html`、`怡达模型_2026年1-3-5日持股策略确认.html`、`怡达模型_D2高开大阴线规则验证.html`。

> **提示时效（v5.4 沿用至今）**：旧版 v5.3 要 D1~D4 四根放量齐才能算 CV 分流，导致 D2 提示实际拖到 D4 收盘才发——**马后炮，D3 买点早就过了**。v5.4 改为 **D2 当天盘后即用 D1+D2 两天出提示**，标签按 **D2/D1 量比预判**（量比≥1.35→加速型，否则平台型；v6 起两者持有期统一3日）。黄金样本标签预判 5/5 正确（平台 0.80~1.27、南极光加速 1.54）。当天提示、D3 真能买；D3/D4 若缩量，历史跟踪按破位/缩量退出兜底。detect 从后往前扫，窗口内多信号时优先返回最新，避免旧信号吃掉当天新提示。v5.4 曾因放宽条件混入噪音（信号451→1787、收益仅+2%量级），v6 的形态精选正是为此而生（410→83、收益+4.21%）。

> **实盘买点（v5.3 沿用）**：D2 盘后出信号当日买不到，改**次日 D3 开盘价买入 + T+1（退出从买入次日 D4 起）**。v5.3 用4天确认筛出的 239 信号 D3 开盘买 +4.92%（马后炮口径，实盘拿不到）；v5.4 当天预判信号的真实收益见上。`entry_rule: d3_open` 可切回 `d2_close` 回退。详见报告 `怡达模型_D3买入时机_实盘约束版.html`。

## 模型逻辑（v5）

**统一骨架**：阴跌 + 收盘<MA60 + 连续4天≥2倍放量 + D1前一日≤2.5倍 + 提示日D2收盘买入

**双标签分流**（互斥）：

| 标签 | 形态 | 阴跌门槛 | 放量节奏 | 跟踪周期 | 2026信号 | 3日最高≥3% | 3日收盘≥3% |
|---|---|---|---|---|---|---|---|
| 🔵 platform | 平台型（怡达原型） | ≥30% | 2~7倍平稳 CV<20% | 5日 + 破位/缩量退出 | 349 | 81.9% | 43.3% |
| ⚡ accel | 加速型（南极光原型） | ≥20% | ≥2倍逐日递增 CV≥20% | 3日固定止盈 | 43 | 100% | 81.4% |

**平台型规则**：
- 阴跌 ≥30%，D1涨停豁免（主板10cm/双创20cm/北交30cm）或 2~7倍，D2~D4严格2~7倍
- CV < 20%（排除逐日爆量，怡达原型仅6.8%）
- 5日退出：收盘<D1实体中点(开+收)/2 或 量<四日均量×0.5，触发当日按最高价结算

**加速型规则**：
- 阴跌 ≥20%（不需深跌），四天量能≥2倍且**逐日严格递增**（v1<v2<v3<v4），CV≥20%
- "加速"是核心：量能斜坡式放大，区别于平台型的平稳；不设7倍上限（加速型可爆量）
- 3日固定止盈，不设破位退出

**最优持有策略（v6 统一3日）**：收益 `ret5` = 策略实际退出收益（非最高价）。2026年1/3/5日三档回测（真实OHLC，402可比信号）证明3日为收益/风险最佳平衡点：

| 持有期 | 全体均值/准确率 | 平台型 | 加速型 | 亏损≥5%比例 |
|---|---|---|---|---|
| 1日 | +1.75% / 35.6% | +1.56% | +2.19% | 9.2% |
| 2日 | +2.41% / 41.5% | +2.30% | +2.65% | 13.4% |
| **3日（选用）** | **+2.03% / 40.0%** | +2.07% | +1.93% | 17.4% |
| 5日（弃用） | +1.36% / 36.6% | +1.18% | +1.79% | **26.9%** |

> 5日收益衰减且深亏翻倍，平台型288只中153只撑不到第5日（破位/缩量退出）。故 v6 统一跟3日：🔵平台型仍保留移动止盈/破位/缩量退出机制（3日窗口内），⚡加速型死拿3日收盘。T+1 从买入次日D4起判定退出。

> 关键发现：加速型D+2即爆发、前3日吃掉大部分涨幅，死拿3日胜率(81%)高于5日(72%)且回撤更小；平台型死拿收盘越拿越少（3日+2.98%→5日+1.95%），但5日内最高价+11.9%、87.8%触及+3%——必须用**宽松移动止盈**保住大牛弹性（激进止盈会把肯特+61%砍到0%，已弃用）。参数 `tp_activate/tp_drawdown`。详见报告 `怡达模型_最优持有策略.html`。

**命中判定**：策略实际退出收益 ≥ 3%（`hmax` 字段另存关注期最高价收益供参考）。参数见 `yida/config.json`。

> 两类本质的区别在"放量节奏"：平台型是"蓄势后平稳放量"，加速型是"越放越猛的连续拉升"。加速型仅占10%信号量，但收盘口径准确率是平台型近2倍、平均收益更高——拟合后统一入口、各用各的止盈周期，互不稀释。

**风控过滤（v5.1，仅平台型）**：从2026年392个信号中回测发现，10只5日大亏损（≤-15%）全部是「下跌途中反抽放量」——D1前5日涨幅为正（+0.4~10.1%）却仍深陷跌势的诱多形态；黄金样本则要么前5日为负（真底部）要么>10%（真突破）。据此新增过滤器，命中任一即剔除：

| 规则 | 条件 |
|---|---|
| A 涨停豁免收紧 | D1涨停 且 前5日涨幅>0 |
| B 反抽异动 | 前5日 0.5~11% 且（\|D2涨跌\|≥8% 或 D2收阴） |
| C 温和阳线诱多 | 前5日 2~11% 且 D2温和阳线 0~6% |

> 回测：10/10 大亏损全拦截、黄金5/5 零误伤、过滤后剩余均值 +2.1%→+3.4%。开关 `config.json → risk_filter`（false 可回退 v5）。加速型零大亏损，不受影响。详见报告 `怡达模型_风控过滤分析.html`。

## 接入方式（已上线）

怡达模型并入仓库统一流水线：

- **样本源**：读取 `common/state/universe.json`（前置流水线样本池，已剔除 ST/立信/监管立案/次新）
- **K线**：复用 `common/state/klines` 共享缓存（严格离线）
- **调度**：已在 `common/registry.json` 注册；另有独立 `yida.yml`（`workflow_dispatch`，独立并发组）
- **台账**：`ctx.record()` 落盘，自动进入次日统一回溯
- **推送**：复用 `common/notify.py` 的 PushPlus 通道（`PUSHPLUS_TOKEN` secret 已配置）

### 微信推送格式（严格两段式 · 双标签 · ★分级）

```
怡达v6 11-25 · 提示2(★1) 观察中1
━━━━━━━━━━━━━━━━
【一、当天提示 11-25·2只(★假破位1)】
`300721` 怡达股份 ★🔵平台 **次日开盘介入** · 勿追尾盘
`300940` 南极光 ⚡加速 **次日开盘介入** · 勿追尾盘
【二、历史提示·观察中 1只（未破位）】
`000823` 超声电子 ★🔵平台 11-20提示 买17.0 观察2/3日 +8.7%✓
━━━━━━━━━━━━━━━━
📌次日开盘介入(T+1次日可卖,勿追尾盘) ｜ ★假破位优先 ｜ 🔵平台/⚡加速均跟3日
```

**只有两段**，分流规则：
- **第一段**：最新提示日那批票；**第二段**：历史提示、仍在观察期、未破位的票
- **★分级**：假破位收复的票标 **★** 并排在最前（一级，收益/准确率显著更高）；普通平台为二级
- 每只票带 **🔵平台 / ⚡加速** 标签；观察天数显示 `已观察/总周期`（统一3日）
- **破位/缩量的票直接剔除**（仅平台型判定；加速型固定止盈不设破位退出）
- **观察期满（3日）** → 自然剔除
- 破位线**一律从K线重算**（signal前一根D1实体中点），不依赖台账字段

独立流水线 `yida.yml` 可手动触发立即推送；统一流水线每天 **北京时间 15:10** 自动运行。

## 使用

```bash
# 仓库内运行（正式：选股+台账+推送）
python3 yida/daily_yida.py

# 本地复跑不推送
python3 yida/daily_yida.py --no-push

# 黄金样本校验（规则变更后必跑）
python3 golden/verify.py
```

推送 token 由 GitHub Secrets 的 `PUSHPLUS_TOKEN` 提供，本地运行需设置同名环境变量。
