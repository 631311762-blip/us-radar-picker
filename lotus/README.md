# 莲花模型 🪷

> 别名：**下探实体一半战法** / 黄金样本模型 V1.4
> 源自莲花控股（600186）、城地香江（603887）、江南化工（002226）三只样本的共同形态提炼。
> 当前版本：**V1.4（ACTIVE）** · 主策略 V1.2 + 精选池 V1.4（四闸门）

---

## 一句话说透

主力动作：**先横盘蓄势 → 放量大涨 → 连续几天假摔挖坑 → 当天又爬回来**。
"挖坑后爬回来"的那一天就是**提示日 T**，次日（T+1）开盘买、再一日（T+2）盘中高点卖，吃洗盘后的二次拉升。
核心只有一句：**跌破大涨那天实体的一半，又收回来。**

---

## 条件（直白版）

### 第一层：主策略 V1.2 —— 判断"是不是这个形态"

| 阶段 | 大白话 | 硬指标 |
|---|---|---|
| ① 大涨前先趴着 | 前20天股价在箱子里小幅晃，主力在憋 | 收盘价变异系数 CV ≤ 9%、区间振幅 ≤ 30% |
| ② 大涨要够猛够真 | 有肉的放量阳线，不是一字板 | 单日涨幅 ≥ 9%、量比 ≥ 1.5、实体 > 0 |
| ③ 挖黄金坑 | 大涨后 3~6 天内，最低价砸破大涨那天的"实体中位线"（开盘+收盘)/2，但当天收盘又爬回开盘价之上 | 间隔 ∈ [3,6] 日、下探最低 ≤ 实体中位线、收盘 ≥ 开盘 |
| ④ 洗盘不失控 | 这几天成交量别乱蹦 | 量 CV ≤ 0.50 |

### 第二层：精选池 V1.4 四闸门 —— 判断"值不值得精推"

| 闸门 | 大白话 | 硬指标 |
|---|---|---|
| 闸门1 别追高 | 提示日当天还得是"没启动"的低位状态，已大涨的一律不要 | 提示日涨幅 ∈ [-2%, +3%] |
| 闸门2 实体要实在 | 剔掉一字板那种虚高假信号 | 大涨实体 ≥ 0.5 元 |
| 闸门3 坑要挖得适中 | 擦一下太浅、砸太深都不要 | 下探深度 ∈ [20%, 150%] |
| 闸门4 大涨前横盘+缩量 | 前期缩量横盘 = 主力吸筹洗干净（**最关键的一道**，萎缩比 < 1.0 是准确率分水岭） | 大涨前15日：箱体振幅 ≤ 28%、收盘 CV ≤ 5%、近5日均量/前5日均量 < 1.0 |

- **四闸门全过 → 精选池**（优先推，低位未启动的干净信号）
- **只过第一层 → 主策略**（覆盖广但风险高些）

---

## 交易规则

- 买入：提示日 T 的**次日（T+1）开盘价**
- 卖出：**T+2 盘中最高价**（理想化卖点，实盘冲高 +5% 分批卖、否则尾盘卖）
- 成功标准：收益率 > 3%
- 适用：A股主板（60/00 开头），排除 ST / 退市 / 新股

## 回测表现（297 只随机池，2026 全年，T+2 口径）

| 版本 | 信号数 | 准确率 | 平均收益 | 胜率 | 最大亏损 |
|---|---|---|---|---|---|
| 主策略 V1.2（放宽版） | 188 | 43.62% | 3.11% | 71.81% | -10.13% |
| 精选池 V1.3（三闸门） | 82 | 41.46% | 2.67% | 68.29% | -4.43% |
| **精选池 V1.4（四闸门）** | **31** | **48.39%** | **3.54%** | **77.42%** | **-3.71%** |

> 第4闸门把信号砍掉约 6 成，但准确率 41.46%→48.39%、胜率 68.29%→77.42%、最大亏损收窄到 -3.71%，风险收益比明显更优。
> 注意：最高价卖点为理想化假设，回测收益系统性高估；随机样本池非全市场，结论用于验证口径趋势。

## 文件

- `config.json` —— 模型参数（主策略 + 精选池四闸门），**推送 token 已脱敏，需本地填写**
- `verify.py` —— 三黄金样本逐条校验脚本（真实行情，独立可跑）
- `pipeline.py` —— 统一选股流水线（候选扫描 → 分级 → 报告 → PushPlus 推送）
- `README.md` —— 本说明

## 使用

```bash
# 校验三黄金样本是否全过（规则变更后必跑）
python3 verify.py

# 选股（指定日期，不推送）
python3 pipeline.py --date 20261127 --dry-run

# 正式选股+推送（需先在 config.json 填 pushplus_token）
python3 pipeline.py
```

依赖：`akshare`、`pandas`、`numpy`、`requests`
