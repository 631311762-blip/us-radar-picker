# 怡达模型 📈

源自怡达股份（300721）2026年8~11月走势提炼的选股模型，已上线 GitHub 并接入统一前置流水线，每个交易日自动运行 + 微信推送。

**GitHub 仓库**：https://github.com/631311762-blip/us-radar-picker （目录 `yida/`）

> **当前版本：v5.1 风控增强版**（2026-11-24）。一套引擎通吃两种强势形态：**🔵平台型**（怡达原型，平稳放量跟5日）+ **⚡加速型**（南极光原型，递增放量跟3日）。两类按 CV 与递增性自动分流、互斥不稀释。基于 4 组平台样本 + 1 组加速样本标定。v5.1 在 v5 基础上新增**下跌中继反抽过滤器**，剔除高位诱多尾部风险（详见下方「风控过滤」）。

## 模型逻辑（v5）

**统一骨架**：阴跌 + 收盘<MA60 + 连续4天≥2倍放量 + D1前一日≤2.5倍 + 提示日D2收盘买入

**双标签分流**（互斥）：

| 标签 | 形态 | 阴跌门槛 | 放量节奏 | 跟踪周期 | 2026信号 | 3日最高≥3% | 3日收盘≥3% |
|---|---|---|---|---|---|---|---|
| 🔵 platform | 平台型（怡达原型） | ≥30% | 2~7倍平稳 CV<20% | 5日 + 破位/缩量退出 | 349 | 81.9% | 43.3% |
| ⚡ accel | 加速型（南极光原型） | ≥20% | ≥2倍逐日递增 CV≥20% | 3日固定止盈 | 43 | 100% | 81.4% |

**平台型规则**：
- 阴跌 ≥30%，D1涨停豁免（主板10cm/双创20cm/北交30cm）或 2~7倍，D2~D4严格2~7倍
- CV < 20%（排除逐日爆量，怡达原型仅6.8%）
- 5日退出：收盘<D1实体中点(开+收)/2 或 量<四日均量×0.5，触发当日按最高价结算

**加速型规则**：
- 阴跌 ≥20%（不需深跌），四天量能≥2倍且**逐日严格递增**（v1<v2<v3<v4），CV≥20%
- "加速"是核心：量能斜坡式放大，区别于平台型的平稳；不设7倍上限（加速型可爆量）
- 3日固定止盈，不设破位退出

**命中判定**：关注期内最高收益 ≥ 3%。参数见 `yida/config.json`。

> 两类本质的区别在"放量节奏"：平台型是"蓄势后平稳放量"，加速型是"越放越猛的连续拉升"。加速型仅占10%信号量，但收盘口径准确率是平台型近2倍、平均收益更高——拟合后统一入口、各用各的止盈周期，互不稀释。

**风控过滤（v5.1，仅平台型）**：从2026年392个信号中回测发现，10只5日大亏损（≤-15%）全部是「下跌途中反抽放量」——D1前5日涨幅为正（+0.4~10.1%）却仍深陷跌势的诱多形态；黄金样本则要么前5日为负（真底部）要么>10%（真突破）。据此新增过滤器，命中任一即剔除：

| 规则 | 条件 |
|---|---|
| A 涨停豁免收紧 | D1涨停 且 前5日涨幅>0 |
| B 反抽异动 | 前5日 0.5~11% 且（\|D2涨跌\|≥8% 或 D2收阴） |
| C 温和阳线诱多 | 前5日 2~11% 且 D2温和阳线 0~6% |

> 回测：10/10 大亏损全拦截、黄金5/5 零误伤、过滤后剩余均值 +2.1%→+3.4%。开关 `config.json → risk_filter`（false 可回退 v5）。加速型零大亏损，不受影响。详见报告 `怡达模型_风控过滤分析.html`。

## 回溯表现（2026年全A股）

| 口径 | 信号数 | 3日最高≥3% | 3日收盘≥3% | 5日最高均值 |
|---|---|---|---|---|
| 🔵 平台型（v3真实规则） | 349 | 81.9% | 43.3% | +10.9% |
| ⚡ 加速型 | 43 | 100% | 81.4% | +24.9% |
| 合并并集（去重） | 392 | 83.9% | 47.4% | +12.4% |

> 两种收益口径的差异来自"盘中冲高后回落"：平台型靠盘中冲高（最高价口径96%正收益），需及时止盈；加速型收盘口径也扎实（91%正收益），实盘更稳。两类信号互斥（重叠0）。

## 接入方式（已上线）

怡达模型并入仓库统一流水线：

- **样本源**：读取 `common/state/universe.json`（前置流水线样本池，已剔除 ST/立信/监管立案/次新）
- **K线**：复用 `common/state/klines` 共享缓存（严格离线）
- **调度**：已在 `common/registry.json` 注册；另有独立 `yida.yml`（`workflow_dispatch`，独立并发组）
- **台账**：`ctx.record()` 落盘，自动进入次日统一回溯
- **推送**：复用 `common/notify.py` 的 PushPlus 通道（`PUSHPLUS_TOKEN` secret 已配置）

### 微信推送格式（严格两段式 · 双标签）

```
怡达·双模型 11-24 · 提示1 观察中2(加速1)
━━━━━━━━━━━━━━━━
【一、当天提示 11-24·1只】
`300940` 南极光 ⚡加速 买14.15 观察0日 +0.0%
【二、历史提示·观察中 1只（未破位）】
`300721` 怡达股份 🔵平台 11-18提示 买16.74 观察3/5日 +24.7%✓
━━━━━━━━━━━━━━━━
🔵平台:阴跌≥30%平稳放量跟5日 ｜ ⚡加速:阴跌≥20%递增放量跟3日
```

**只有两段**，分流规则：
- **第一段**：最新提示日那批票；**第二段**：历史提示、仍在观察期、未破位的票
- 每只票带 **🔵平台 / ⚡加速** 标签，观察天数显示 `已观察/总周期`（平台5日、加速3日）
- **破位/缩量的票直接剔除**（仅平台型判定；加速型固定止盈不设破位退出）
- **观察期满** → 按各自周期自然剔除
- 破位线**一律从K线重算**（signal前一根D1实体中点），不依赖台账字段

独立流水线 `yida.yml` 可手动触发立即推送；统一流水线每天 **北京时间 15:10** 自动运行。

## 使用

```bash
# 仓库内运行（正式：选股+台账+推送）
python3 yida/daily_yida.py

# 本地复跑不推送
python3 yida/daily_yida.py --no-push

# 黄金样本校验（规则变更后必跑）
python3 golden/verify.py
```

推送 token 由 GitHub Secrets 的 `PUSHPLUS_TOKEN` 提供，本地运行需设置同名环境变量。
