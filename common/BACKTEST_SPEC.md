# 统一回溯口径规范 v1.0

确立日期 2026-11-24，所有选股模型共用。

## 口径
- 提示日 D0 = 模型发出信号的交易日；所有"天"按交易日计（跳周末/节假日，停牌顺延）。
- 买入：D+1（第二天）开盘价 P_buy。
- 卖出（均为当日最高价）：1 -> D+1（第二天）；3 -> D+3（第四天）；5 -> D+5（第六天）；10 -> D+10（第十一天）。
- 收益率 R_n = (H_(D+n) - P_buy) / P_buy * 100%。
- 胜率：R_n > 0 的样本占比；收益率：R_n 的算术平均。
- 复权：前复权(qfq)。
- 边界：T+1 一字涨停买不进按理想化仍计入；凑不齐 D+n 的样本该周期剔除。

## 实现
见 common/backtest_spec.py：evaluate_signal() 算单信号，summarize() 批量统计，load_bars_qfq() 取数。

阳普医疗 300030 提示日 2026-10-29：D+1=10-30 开盘6.05买入，D+1/3/5/10最高价卖出收益率 20.8/25.6/17.0/30.2%。
