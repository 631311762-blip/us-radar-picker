# 回溯口径统一规范 v2.0（权威·所有模型强制）

> 确立日期：2026-11-26　｜　适用范围：GitHub 仓库所有选股模型（含生产前置层 kit.py 回溯结算）
> 本规范**取代**此前所有口径（含 v1.0、T+1 修正版、最高价/收盘价专项版）。所有模型回溯必须按此执行，历史统计有误的按此重算更新。

## 一、时间基准（T+1 铁律）

- **提示日 D0**：模型发出信号的交易日（收盘后确认）。
- **买入日 = D+1**：提示日后第 1 个交易日，**开盘价**买入。
- **当天不能买卖**：D+1 买入当天不可卖出，最早 D+2 才能卖。
- 所有"天"均指交易日（跳过周末/节假日），停牌顺延至下一交易日。

## 二、卖出日与价格口径（核心）

| 持有周期 | 卖出日 | 收益计算 | 说明 |
|---|---|---|---|
| **1 日** | D+2 | **最高价**卖 + **收盘价**卖（两套都算） | 双口径并列统计 |
| **3 日** | D+4 | **最高价**卖 + **收盘价**卖（两套都算） | 双口径并列统计 |
| **5 日** | D+6 | **最高价**卖 + **收盘价**卖（两套都算） | 双口径并列统计 |
| **10 日** | D+11 | **仅收盘价**卖 | 只用收盘价，不算最高价 |

> 即：1/3/5 日各产出"最高价收益"和"收盘价收益"两组数；10 日只产出"收盘价收益"一组。

## 三、收益率公式

```
R = (卖出价 − 买入价) / 买入价 × 100%
```
- 买入价 = D+1 **开盘价**
- 卖出价 = 对应卖出日的最高价或收盘价（按上表）
- 复权口径：前复权(qfq)，共享行情表

## 四、胜率判定（关键变更）

- **胜 = 收益率 R > 3%**（不再是 R>0）。
- 胜率 = 满足 R>3% 的样本数 ÷ 该周期有效样本数 × 100%。
- 平均收益 = 该周期全部样本 R 的算术平均（含负收益样本）。
- 每套价格口径（最高价/收盘价）各自独立统计胜率与平均收益。

## 五、输出结构（每个模型回溯结果）

对 1/3/5 各产出两套、10 日一套，共 7 组指标：

```
t1_high  : {samples, win_rate(R>3%), avg_return}   最高价卖
t1_close : {samples, win_rate(R>3%), avg_return}   收盘价卖
t3_high  / t3_close
t5_high  / t5_close
t10_close: {samples, win_rate(R>3%), avg_return}   仅收盘价
```

## 六、生产系统落地（kit.py）

- `HORIZONS = (1, 3, 5, 10)`
- 基准价 `base = bars[idx]["open"]`（idx = 推荐日 D0 之后第一根 K 线 = D+1）
- 卖出日 `j = idx + h`（h=1→D+2, 3→D+4, 5→D+6, 10→D+11）
- 1/3/5：`ret_high = bars[j]["high"]/base-1`、`ret_close = bars[j]["close"]/base-1`
- 10：仅 `ret_close = bars[j]["close"]/base-1`
- `WIN_THRESHOLD = 0.03`
- 综合胜率：以 5 日收盘价口径为主（样本最充分且保守），供 params 调参使用。
